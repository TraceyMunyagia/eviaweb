# Evia Web website

## Goal
Build a polished, mobile-first multi-page website that turns small and growing businesses into quote requests, using deep plum, champagne gold, warm cream, generous whitespace, strong typography, and restrained motion.

## Pages and shared structure
- Add a sticky header and full footer shared across Home, Portfolio, Packages, How It Works, About, Contact, and Get a Quote.
- Use separate pages with page-specific titles, descriptions, social metadata, and canonical links.
- Keep the primary “Get a Quote” action visible throughout, with an accessible mobile menu.
- Add Privacy Policy and Terms & Conditions pages linked from the footer.

## Home
- Build the supplied headline-led introduction with a layered website-preview composition.
- Add service, benefits, portfolio preview, package preview, six-step process, and final deep-plum call-to-action sections.
- Use restrained entrance, button, card, and image-transition effects with reduced-motion support.

## Portfolio
- Showcase Rentra, Evia, Trasan Recruitment, and Trasan Education using captured screenshots from the supplied sites.
- Each project will use a self-contained visual carousel with automatic rotation, arrows, dots, title, and business type; previews will not link to the live sites.
- Optimize and lazy-load showcase imagery.

## Packages and optional features
- Present Starter, Growth, and Premium exactly as supplied, highlighting Growth as “Most Popular.”
- Include package CTAs, the delivery-timeline note, and an unpriced additional-features section.

## How It Works, About, Contact, Quote
- Build the seven-step process timeline and concise About page.
- Add contact details for +254 796 675 566, eviake@gmail.com, and Evia Web’s Instagram, TikTok, and Facebook handles.
- Build an accessible contact form and a three-step quote form with progress, inline validation, previous/next controls, and a clear success state.
- Forms will demonstrate the full client-side experience only; submission storage or email delivery will remain unconfigured, as requested.

## Technical details
- Define the complete token-based visual system in the global stylesheet and use the existing interface components.
- Use semantic markup, strong keyboard/focus states, responsive layouts, optimized local images, and minimal JavaScript.
- Add Organization/ProfessionalService structured data, descriptive alt text, correct heading order, robots support, and route-level metadata.
- Verify layout and interactions at mobile and desktop sizes, then resolve any preview or build errors.
